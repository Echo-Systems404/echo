The format for notes Echo saves to your memory vault with memory_save. Yours to
edit: Echo reads it but can't change it. It's added to the memory_save tool's

- Start with a one-paragraph summary.
- Then a brief: the key facts, decisions, and why, as short lines.
- End with footnotes: sources, dates, related notes as [[links]].
