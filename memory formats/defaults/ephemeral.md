<!--
The format for ephemeral memory (one summary per saved conversation). Yours to
edit: Echo reads it but can't change it. It's added to the ephemeral_save tool's
description (up to 1500 characters; comments don't count).
-->
- Title: a few words naming what the conversation was about.
- Summary: a nuanced account of the whole interaction: what was discussed and
  worked on, decisions and why, outcomes, files touched, and what is still open.
- End with short footnotes for details worth keeping: names, paths, numbers.
- Saving again in the same conversation replaces its summary, so include
  everything still relevant, not just what's new.
