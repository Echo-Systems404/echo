<!--
The format for transient notes. Yours to edit: Echo reads it but can't change
it. It's added to the transient_edit tool's description (up to 1500 characters;
comments like this one don't count). /options → Memory layers shows it.
-->
- One entry per project or topic, titled with its name (a website, an app, a trip).
- Short lines, not prose. Lead with what you'd need to pick the work back up:
  names and renames, paths, ports, dependencies, functions and variables, and
  why each decision was made.
- Add to the entry the information belongs to; start a new entry only for a new subject.
- Keep entries current: replace what changed instead of piling up old versions.
