The format for task notes (written when a task's context fills or its time runs
out). Yours to edit: Echo reads it but can't change it. It's added to the

- Done: what is finished, with file paths.
- Next: the remaining steps, in order.
- Know: names, paths, decisions, and anything that failed and why.
- Writing notes replaces earlier ones, so include everything still relevant.
